# PPE Reliability

YOLO11 PPE compliance detection, extended with label-free reliability estimation and gated self-improvement (SVPCET Nagpur).
Every number that can appear in the paper lives in `results/results.csv` and is regenerated by the command in its `command` column.

## Setup

Python 3.10 or newer.

```bash
python -m venv .venv
# Windows: .venv\Scripts\activate    Linux/macOS: source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env        # Windows: copy .env.example .env   (only needed for alerts)
```

The baseline detector is committed at `weights/best.pt` (YOLO11s, 11 classes, trained with Ultralytics 8.3.21).
Datasets are not committed; see `datasets/README.md`.

## Run inference

```bash
python -m ppe.infer                                  # webcam 0
python -m ppe.infer --source path/to/images/         # folder of images
python -m ppe.infer --source clip.mp4 --show         # video with a preview window (q to quit)
python -m ppe.infer --source path/to/images/ --save-dir runs/annotated
```

Settings come from `configs/infer_default.yaml`; pass another file with `--config`.
Each run writes `runs/logs/run_<UTC time>.jsonl`: a `run_start` line (config, weights, thresholds, class names, git commit), one `frame` line per frame, and a `run_end` line.
A frame line holds every detection (class, confidence, box, track ID), the per-person decisions, and the orphan PPE boxes that no person box contains.

## Run the dashboard

```bash
python -m app.app                    # http://127.0.0.1:5000, camera from 'source' in the config
python -m app.app --host 0.0.0.0     # reachable from other machines on the network
```

The dashboard calls the same `ppe.infer.Pipeline` and writes the same JSON-lines log.
Twilio alerts are off unless `ENABLE_TWILIO_ALERTS=true` in `.env`; see `ppe/alerts/README.md`.
Team photos for the About page are not committed; put them in `app/templates/team/`.

## Compliance rules

- A PPE or `no_*` box belongs to the person box that contains its centre (the smallest one if several do).
- Classes are matched by exact name, as stored in `best.pt`. The person class is `person` (lower case). The eye-protection class is `goggles`, its negative is `no_goggle`.
- Per item: a `no_*` box is a **violation**; a positive box alone is **present**; neither is **unknown**, not a violation.
- `vest` has no negative class in Construction-PPE, so it is only present or unknown.
- The `none` class is logged but not used for compliance.
- A person is **violation** if any required item is a violation, **compliant** if every required item is present, otherwise **unknown**.

Tests: `python -m pytest tests`.

```
app/        Flask dashboard, calling ppe.infer
results/    results.csv, promotions.csv, figures/

```
