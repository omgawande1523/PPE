# Phase 1: honest baseline (best.pt on the test split)

Every number below is copied from `results/results.csv`, run `p1_baseline_yolo11s_20261007T175332Z`
(code commit `74dc92ae82`), and is regenerated by:

```bash
python -m ppe.eval --config configs/eval/baseline_yolo11s_test.yaml
```

Setup: `weights/best.pt` (YOLO11s), Ultralytics 8.3.21, torch 2.6.0, CPU, fp32, 640 px, seed 0.
Dataset: Construction-PPE, byte-identical to the Ultralytics release (sha256 of every file checked).
The run was repeated with the same seed (`p1_baseline_yolo11s_20261007T175540Z`); all 241 rows are identical (`python -m ppe.eval --compare ...`).

## Check that the evaluation reproduces the notebook

On val, the Ultralytics protocol gives mAP@0.5 0.639, mAP@0.5:0.95 0.315, P 0.739, R 0.591, and the same per-class values as the brief's table.
So the eval code measures what the training notebook measured; the test numbers below come from the same code path.

That is why person-level recall is higher than box recall for the same class.

## What this does and does not prove

- It does show that the 0.639 was a val number that does not carry over to test unchanged: test mAP@0.5 is 0.570, 0.069 lower.
  The two 95% intervals overlap, so with about 140 images per split this gap alone is not strong evidence of a real val/test difference;
  part of it is sampling noise between two small splits. It is the honest baseline number for the paper, with its interval.
- The violation classes are the weak point on both splits. On test the detector finds 22.5% of no_helmet, 30% of no_goggle, 19% of no_gloves and 0 of 23 no_boots boxes.
  Each has 23 to 58 instances, so the intervals are wide (about ±0.15), but every upper bound is below 0.49.
- no_boots has only 4 val instances, so the val split cannot measure it; the 0 of 23 on test is the first real measurement and it is a total failure.
  The operating confidence was chosen on a val split that barely contains this class.
- At the person level, 20 of 47 labelled violators on test raise no alert, and 43 of 236 labelled persons are not detected as persons.
  False alerts on labelled non-violators are rare (0 of 189); the false alerts that do occur come from predicted persons that match no labelled person.
- It does not measure performance on a different site: val and test are random splits of one dataset. That is Phase 2.
- It does not show seed-to-seed variance of the training recipe. The six retraining runs (YOLO11n/s, seeds 0 to 2) are prepared but not run; see `results/missing.md`.
- Only exact duplicates between splits were checked (none found). Near-duplicate frames across splits were not checked.
