# Phase 2: site shift (synthetic conditions measured; real sites missing)

Every number below is copied from `results/results.csv`, run `p2_shift_yolo11s_20261007T181833Z` (code commit `6e7dd25c09`), regenerated by:

```bash
python -m ppe.shift --config configs/shift/p2_shift_yolo11s.yaml     # all cells, appends to results.csv (about 20 min on CPU)
python -m ppe.shift --table p2_shift_yolo11s_20261007T181833Z        # the full table: results/phase2_shift_table.md
```

Setup: `weights/best.pt` (YOLO11s), Ultralytics 8.3.21, torch 2.6.0, CPU, fp32, 640 px, seed 0, operating confidence 0.28 (chosen on val in Phase 1, checked against results.csv, never re-chosen).
Every cell uses the same 141 test images (golden set v1, hash-verified before the run). The clean cell was re-measured in the same run: all 83 rows it shares with the Phase 1 run are identical.
Each corrupted image has its own random draw, seeded by (seed, condition, severity, file name). Examples: `results/figures/p2_shift/corruption_examples.jpg`. Heatmap of every recall change: `results/figures/p2_shift_yolo11s_20261007T181833Z/shift_recall_delta.png`.
Intervals are 95% percentile intervals from 1,000 bootstrap resamples of images, **paired**: clean and corrupted recall are computed on the same resampled images, so the interval is for the drop itself.

## Answer so far to question 1 (how much accuracy is lost off-site)

**Not measured yet.** Synthetic conditions are not a different site. SH17, CHV and own-site footage are missing (see the last section); they are the cells that answer question 1.

## Question 2: which classes and conditions lose the most (synthetic)

Test mAP@0.5 is 0.570 clean. Micro box recall over all classes is 0.715. Mean recall over the four violation classes is 0.179. 27 of 47 labelled violators are flagged (0.574).

| Condition | mAP@0.5, s1 / s2 / s3 | Δ micro recall at s3 [95%] | Δ violation macro recall at s3 [95%] | Violators flagged at s3 (clean 0.574) |
|---|---|---|---|---|
| low light | 0.553 / 0.473 / 0.259 | -0.488 [-0.55, -0.43] | -0.068 [-0.14, -0.00] | 0.468 |
| haze / dust | 0.561 / 0.559 / 0.542 | -0.072 [-0.09, -0.05] | -0.026 [-0.08, +0.01] | 0.596 |
| motion blur | 0.540 / 0.452 / 0.304 | -0.424 [-0.47, -0.38] | -0.154 [-0.24, -0.08] | 0.191 |
| JPEG | 0.549 / 0.506 / 0.292 | -0.328 [-0.38, -0.28] | -0.165 [-0.24, -0.10] | 0.085 |
| rain | 0.564 / 0.520 / 0.355 | -0.294 [-0.34, -0.25] | -0.156 [-0.23, -0.09] | 0.149 |
| downscale (distant camera) | 0.552 / 0.456 / 0.343 | -0.221 [-0.26, -0.19] | -0.163 [-0.24, -0.09] | 0.170 |

Findings, each with what it rests on:

1. **Severity 1 of every condition costs little.** mAP@0.5 drops by 0.006 to 0.030 and micro recall by 0.006 to 0.064. That is a small loss and it goes in the paper as a finding. Only motion blur s1 clearly excludes zero (micro recall -0.064 [-0.09, -0.04]); the other five intervals end at about zero.
2. **The severe end costs a lot.** At severity 3, mAP@0.5 falls to 0.26 to 0.36 for low light, blur, JPEG, rain and downscaling. Haze is the exception, falling only to 0.542 even at its strongest.
3. **no_goggle is the most fragile violation class.** It loses recall in all 18 cells. The drop ranges from -0.030 to -0.303, and -0.303 means it goes to 0 of 33. Already at JPEG s2 (quality 15) it falls by 0.212 [-0.36, -0.08]. With n = 33 the intervals are wide.
4. **no_helmet holds up until the severe end, then breaks.** At JPEG s3 it falls by -0.200 [-0.37, -0.07], at downscale s3 by -0.175, and at rain s3 by -0.150 (all n = 40).
5. **Low light behaves differently from the rest.** At s3 the positive classes collapse: helmet recall falls from 0.922 to 0.068, gloves from 0.761 to 0.086 and goggles from 0.750 to 0. But no_helmet recall stays at 0.250, and 0.468 of violators are still flagged. Meanwhile the share of false alerts among predicted violation flags rises from 0.161 (5 of 31) to 0.447 (17 of 38), and 7.4% of labelled non-violators get flagged (0 clean). Dark scenes therefore push the model towards "no PPE", which is a false-violation failure rather than a silent one. This is inferred from the rows above and has not been tested further.
6. **Blur, JPEG, rain and downscaling fail silently.** At s3 the alerts mostly disappear: 4 to 12 predicted violation flags remain, against 31 clean. Micro precision stays between 0.75 and 0.85 in every cell except low light s3 (0.652), so precision does not reveal the drop. For Phase 4 this means a label-free monitor cannot rely on alert precision. It needs signals that see the missing boxes.
7. **Person recall is the most robust class.** Apart from low light s3 (-0.254), motion blur s3 (-0.386), JPEG s3 (-0.233) and rain s3 (-0.182), it moves by less than 0.18. A COCO person detector as a disagreement signal (Phase 4) is therefore most informative under exactly those four cells.

## Cells that are not comparable, and why

- **no_boots, every condition.** Clean recall is already 0 of 23, so a drop cannot be observed (floor). The only nonzero cell is downscale s1, where 1 of 23 is found. The table marks these cells `floor`.
- **Downscale versus the other conditions.** It changes geometry, not just pixels. Content is shrunk into a same-size frame padded with grey (114), and labels are shrunk with it. Its drop mixes "objects are smaller" with "there is a grey border the training images never had". It measures distance and is not a sensor fault.
- **Low light and haze also change the black letterbox bars** that many test images already carry (the example in the figure has them). Low light darkens them further. Haze turns them grey-brown, so the frame edge looks different from training.
- **Synthetic cells versus real sites.** All 18 cells are the same 141 Construction-PPE images, with the same people, sites and label conventions. They measure robustness to image degradation, not site shift. They cannot answer question 1.
- **Person-level rows** rest on 47 labelled violators in total and 13 to 39 per item. Their intervals are wide; most "any violation" change intervals are 0.2 to 0.4 wide. Box-level class recall rests on 23 to 236 instances per class (`n` column).
- **SH17 and CHV, when added.** Only helmet, vest, gloves, boots and person (SH17), or helmet, vest and person (CHV), can be scored. Neither set has `no_*` classes, so violation recall and person-level metrics cannot be measured on them. SH17 "shoes" is any footwear while our "boots" is safety boots, so boots recall on SH17 is not the same quantity. Precision on those sets counts every unlabelled class as absent, which is only valid for the mapped classes. Their drop compares different images, so its interval comes from independent resamples (wider) rather than paired ones.
